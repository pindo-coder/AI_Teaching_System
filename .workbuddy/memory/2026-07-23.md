评审发现的关键问题（按优先级）：
1. 依赖管理双轨：根目录 pyproject.toml（uv）与 backend/requirements.txt（pip）并存；根 .venv 已损坏（uv 把 Python 装在 /tmp/ai-teaching-uv-python，被系统清理，解释器悬空）。跑测试临时方案：PYTHONPATH 指向 .venv/lib/python3.13/site-packages + 受管 Python 3.13.12。建议尽快统一为单一依赖源并重建 venv。
2. 安全缺口：全站无速率限制（登录/注册/AI 接口尤其危险）；JWT 存 localStorage；无 refresh token；无管理员审计日志。
3. 生产默认 SQLite（docker-compose 默认 DATABASE_URL=sqlite）；单 uvicorn worker；无缓存层；Chroma 嵌入式不可多实例共享。
4. 工程化缺口：无 CI/CD、无 linter/formatter 配置（ruff/ESLint 都没有）、无前端测试、无监控告警。
5. 代码层面：knowledge.py endpoint 576 行偏厚；db/models.py 仅为集中导入器，命名易与 app/models/ 混淆；15 个 datetime.utcnow() deprecation 警告。

亮点：分层架构清晰（API/Service/Repository/RAG）、三层权威加权 RAG + 证据配额防幻觉、引用页码校准、批量导入断点恢复、Alembic 迁移、非 root Docker 多阶段构建、文档齐全。

# PPT 断点与缺失插图补全

## 行为约定

“继续生成未完成部分”（`resume=true`）与“重新生成整套”不同：

- 教学内容、资料快照、页数、视觉偏好、模板参考、文本模型或生成规范发生变化时，安全新建作业。
- 只更换成图或视觉复核 API Key，不重新策划内容、不重新设计已通过校验的 SVG。
- 有效的已有图片继续保留；只请求有槽位且图片缺失、损坏或先前被拒绝的页面。所有图片已齐全时，不请求成图模型。
- 配图配置不可用时保留插图槽及文字版式，记录未完成数量；配置恢复后仍可续跑，不把无图降级冒称为完整成功。
- 新增图片先写入断点，再报告进度/检查取消；取消或导出失败后，不重复生成已经保存的有效图片。
- 补图后仍须重新导出并检查最终 PPTX/预览。旧可下载文件保留到新成品成功，发布仍需教师确认。
- `resume=false` 明确新建作业，不会被缓存变成“只补图”。已完成作业也不会因为点击续跑而恢复更早的失败草稿。

## 分离的身份

v5 内容断点以同一任务、同一所有者及输入/证据/生成规范为界。文本模型地址与名称仍参与匹配，但认证凭证不参与内容身份。
成图模型、接口与复核策略单独记录为 `image_fingerprint`，不再作为正文和 SVG 的缓存依赖。
原有效图片由其原来的文件和复核状态验证，轮换密钥或切换图片服务不会抹掉已付费成果；需要重新绘图时使用单张换图或显式整套重生成。

规划阶段的图片预算来自教师选择及页数/数量上限，不随密钥是否暂时配置、服务是否启用而改变。
插图仍只承担原有槽位的内容，不移动文字、不自动给没有插图槽位的旧页面新增图片。

## v4 兼容

旧 v4 断点仅保存整体摘要，包含当时的成图/复核密钥摘要，不能仅凭“标题相同”安全导入。
首次 v5 续跑会用当前输入、所有者、证据和生成规范，结合数据库保留的成图与视觉能力各最近 16 条配置历史，重建精确的 v4 指纹。
仅导入匹配的未完成断点；拷入 v5 命名空间，原断点及其 latest 指针不变，不删除旧图片。
已有 v5 作业时不回退到历史 v4 失败稿。损坏 JSON、越界路径、符号链接、其他任务或不匹配指纹一律不导入。

如果旧凭证历史已丢失、加密主密钥已变更无法解密、旧文本模型认证已更换，或旧输入/规范无法精确复原，会安全重建。
不承诺导入更早的无指纹或 PptxGenJS 草稿；已有旧课件仍可下载。此兼容过程只读配置历史，不验证旧密钥、不发送模型请求，也不保存或输出明文密钥。

## 进度与检查

`ppt_workflow.resume` 增加 `generated_images`、`pending_images`、`legacy_imported`，保留已有的页面/图片复用计数。

`multimodal` 另外记录 `reused_count`、`newly_generated_count`、`missing_count`；`requested_count` 是已规划图片槽总数，不因服务不可用而变为零。

## 进度无需手动刷新（后续修复）

旧页面仅靠 SSE 快照，断线时只读取一次详情；代理静默结束流时甚至不会进入错误分支，页面可能一直保留旧百分比。
现改为任务级监听器：SSE 通知变化，串行 GET 获取权威快照，另以每 5 秒一次查询兜底。延迟的 SSE 快照本身不会覆盖已取得的新进度。
查询不创建、重试或重新生成任务，也不调用成图/文本模型。

- 后台等待模型期间每 10 秒发 SSE 注释心跳，不改变页面进度。
- 前端对正常 EOF、连接异常和 30 秒无字节的连接进行重连，重连退避上限 30 秒。
- GET 网络异常时同样退避，保留最后收到的状态并显示同步提示；401/403/404 停止自动请求，不把连接失败当作 AI 任务失败。
- 终态、等待人工确认、离开页面或切换任务时取消旧连接、定时器和请求；重复订阅合并，迟到的旧请求不可覆盖新任务。
- 切回可见页面或网络恢复时立即补查；相同状态的周期查询不强制切换教师正在查看的成果页。
- 百分比仍取决于后台阶段/实际完成页数。单次模型调用期间可能暂时不变，不使用计时器伪造完成进度。

验证：`corepack pnpm test:agent-progress` 新增 30 项传输/监控/真实 Vue 监听接线回归，
其中覆盖静默长连接、提前 EOF、心跳、断线、轮询、旧快照、换任务、取消监听及终态自动停止。
后端以隔离 SQLite 和虚拟时钟实际消费 SSE 生成器，验证心跳与已提交页数变更；不冒称实际公网断网或浏览器人工验收。

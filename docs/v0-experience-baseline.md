# V0 体验基线

更新日期：2026-07-28

本基线对应重大升级方案的第一阶段。目标不是提前接入完整智能体，而是先固定角色入口、页面结构、任务状态和证据表达，避免后续功能继续堆叠到同一页面。

## 1. 三条核心路径

### 学生：学习—反馈

1. 从“今日学习”查看继续学习、教师任务和学习状态。
2. 从“课程学习”进入教材专题，再进入预习、巩固或冲刺阶段。
3. 在“讨论共建”提交观点，在“笔记复习”沉淀个人理解。
4. 在“学习任务”查看教师布置内容和真实完成进度。

### 教师：备课—发布

1. 从“教学工作台”查看待办、任务完成率和候选资料。
2. 在“课程备课”选择课程与教材专题，确认教学任务。
3. 构建并冻结证据包，证据优先级为中央材料、教材、地方材料。
4. 后续阶段由 Agent 生成课纲、讲稿和课件，教师预览后发布。
5. 在“课堂教学”查看学生完成详情，在“师生共建”审核讨论内容。

### 管理员：发现—审核

1. 从“平台概览”查看资料、教学班和异常状态。
2. 候选资料进入“资料审核”，先核验来源、正文、日期、适用范围和索引状态。
3. 只有人工确认并发布的资料可以进入教学检索和 AI 引用范围。
4. 索引失败、正文为空或资料范围不明时禁止发布。

## 2. 角色导航

每个角色最多显示五个一级入口。

| 角色 | 一级入口 |
| --- | --- |
| 学生 | 今日学习、课程学习、讨论共建、笔记复习、学习任务 |
| 教师 | 教学工作台、课程备课、课堂教学、师生共建、资料动态 |
| 管理员 | 平台概览、教学管理、资料审核、任务监督、内容互动 |

桌面端使用 224px 侧栏，移动端在 1024px 以下切换为抽屉导航。64px 上下文栏始终显示当前课程、专题或教学班，并保留搜索、后台任务和消息入口。

## 3. 状态与证据表达

- 任务状态：未开始、进行中、已完成、已逾期、已取消。
- 资料状态：处理中、可用、索引异常。
- 审核状态：待审核、已发布、已拒绝、已归档。
- 智能体长任务预留：排队中、运行中、需要确认、已完成、失败。
- 中央材料的“权威”只表示来源等级，不表示可以跳过人工审核。
- 所有教学生成结果必须能够回到教材页码、权威原文或已确认资料。

## 4. 第一阶段页面

- 角色工作台：根据账号角色加载学生、教师或管理员视图。
- 课程备课：固定“设置任务—构建证据—生成课纲—生成成果—预览发布”五步流程。
- 资料审核：提供候选资料、原文证据和审核决定三栏结构。
- 全局壳层：统一桌面侧栏、上下文栏、移动端抽屉、消息与长任务入口。

第一阶段只实现前两步可操作链路，并为后续 Agent 运行记录和流式生成保留稳定界面；不使用前端假数据伪造生成结果。

## 5. 验收口径

- 角色一级导航不超过五项，且不同角色入口明确区分。
- 390px、768px、1024px、1280px 宽度下不产生页面级横向滚动。
- 所有主要操作具有清晰状态、空状态和错误状态。
- 资料未完成索引或没有正文分块时，发布按钮不可用。
- 教师冻结证据包前必须选择课程与教材专题，且证据来自已发布资料。
- TypeScript 类型检查与 Vite 生产构建通过。
